我是 **mr wu**（GitHub: [ytuio21](https://github.com/ytuio21)）。

## 为什么做这个站

找工作这件事，过去靠一份简历、几轮面试，信息是封闭的。但 AI 让"一个人能干多少事"变成了一个可以展示的东西——前提是你得把做过的事留下来。

所以我把每一次尝试都记下来：学了什么、用了什么工具、卡在哪、怎么解决的。这里既是我的求职记录，也是我的作品集。

## 这个站是怎么做的

这个网站本身就是一次 AI 实践：

- 内容是纯 Markdown，写在 `content/` 目录里
- 构建器是自己写的零依赖 Node 脚本（`src/build.mjs`），没有框架
- 每次 `git push` 后由 GitHub Actions 自动构建并发布到 GitHub Pages
- 全部代码在 [GitHub](https://github.com/ytuio21) 上公开
